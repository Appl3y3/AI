# 拾光影院

本地运行的影视聚合播放器。日漫 / 剧场版 / 特摄 / 电影 / 剧集 / 综艺 / 短剧 / 纪录片，
片子来自 5 个公开采集接口，在本机起一个服务做聚合与代理，浏览器里直接播放。

## 启动

双击 `start.cmd`，或：

```bat
node server.js
```

然后打开 http://127.0.0.1:8787

端口被占用时换一个：`set PORT=9000 && node server.js`

## 功能

- **首页**：今日热播 hero 轮播 + 最近热播动漫 + 最新更新
- **分类**：动漫 / 日漫 / 剧场版 / 特摄 / 电影 / 剧集 / 综艺 / 短剧 / 纪录片，
  支持按年份、地区筛选，支持换源（同一部剧自动列出各片源的版本）
- **特摄专区**：按关键词（假面骑士、奥特曼、超级战队、铠甲勇士、牙狼…）跨源聚合
- **放送表**：番剧每周更新时间表，数据来自 AniList，按本地时区分 7 天
- **播放器**：hls.js 播放 m3u8，倍速 / 选集 / 换线路 / 全屏 / 音量
- **弹幕**：发送后存本地服务，同一浏览器的人都能看到
- **续播**：自动记录进度，再次进入从上次位置继续（含「已续播至 00:04」提示）
- **个人中心**：浏览记录、我的收藏、观看统计
- **设置**：自动跳过片头 / 片尾（秒数可调）、自动连播、记住倍速、弹幕开关 / 字号 / 不透明度

## 实现要点

- **所有视频流和海报都走本地代理**。源站普遍没有 CORS 头，且图床有防盗链，
  直接在前端加载会被浏览器拦掉。`/api/proxy` 会把 m3u8 里的分片地址、
  AES-128 key 地址、子播放列表全部改写成代理地址，一并解决 CORS 与 Referer。
- **采集站的分类 id 每个源都不一样**，且一级分类（电影/剧集/综艺/动漫）在多数源里是空壳，
  真实数据全在二级分类。所以每个源按实测数据维护了一份 id 数组映射。
- **上游 `area` 过滤参数基本失效**（只有 ffzy 生效），改成拉大候选池后在服务端本地过滤。
- **放送表给的是日文原名，采集站只有中文译名**，直接搜是 0 条。
  搜索时若关键词含假名且无结果，会用 B 站番剧搜索换到中文译名再搜一轮，并在页面提示
  「已按『鬼灭之刃 柱训练篇』匹配」。
- **上游数据有脏值**（`vod_area` 写「题本」「暂无简介」，uku 把日漫的 `type_name` 标成「国产剧」），
  已在 `normArea` / `fixType` / `cleanContent` 里统一清洗。

## 声明

所有片源来自公开采集接口，本项目只做聚合展示，不存储任何视频文件，仅供学习交流。
